HawkerGo User Guide

How to use the Customer, Hawker, and Admin portals.

Customer site Hawker portal Admin panel

Getting started

  1. Start Apache and MySQL in XAMPP.
  2. Import DATABASE FILE/hawker.sql into MySQL.
  3. Open the customer site, hawker portal, or admin panel using the buttons above.

Customer portal

Browse stalls, add items to cart, checkout (login, register, or guest), and track orders.

Main features

  • My Cart — Review and change quantities before checkout.
  • My Orders — Track queue number and order status.
  • Reviews — Rate dishes and stalls after order is completed.
  • Forgot password — Reset using username or email from the login page.

Hawker portal

Each stall has one portal account linked to the stall name in the database.

Sign in

  1. Select your stall name (with photo).
  2. Enter your password.

Register

Choose an available stall, set username and password. Stalls that already have accounts show as registered.

Day-to-day tasks

  • Manage incoming orders (preparing → ready → complete).
  • Mark menu items sold out.
  • View statements and report payment issues to admin.

Admin portal

Manage customers, stalls, menus, all orders, ordering control, payment issues, and sales reports.

Troubleshooting

  • Database errors — Check MySQL is running and database hawker exists.
  • Missing images — Files should be in admin/Res_img/.
  • Hawker cannot register — Stall may already have an account; use Forgot password or add a new stall in admin.
